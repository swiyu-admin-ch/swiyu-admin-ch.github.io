# Standards & Specifications

This directory contains local copies of relevant standards and Swiss E-ID specifications for our RAG server (**Context7**).

### Purpose
These files serve as the central knowledge base for the AI Security Scanner.

### Why store locally in the repository?
* **Unified Index:** All specifications are accessible via a single Context7 library ID.
* **Pinned Versions:** Prevents *specification drift* caused by external updates.
* **Better Quality:** Clean parsing without HTML overhead, navigation noise, or external fetch errors.


### Standards (Overview )
* **OpenID Foundation:** OID4VCI 1.0 (`openid-4-verifiable-credential-issuance-1_0.md`), OID4VP 1.0 (`openid-4-verifiable-presentations-1_0.md`).
* **IETF RFCs & Drafts:** DPoP (RFC 9449), SD-JWT (RFC 9901), JAR (RFC 9101), JWT (RFC 7519), UUID (RFC 9562), SD-JWT VC, Token Status List (TSL).
* **W3C & DIF:** W3C DID Core v1.0, W3C Digital Credentials API, `did:webvh` Method Spec.
